Google Colab Setup Guide (مرحلہ وار رہنمائی)

🇵🇰 گوگل کولیب (Google Colab) استعمال کرنے کا طریقہ:

  1. سب سے پہلے colab.research.google.com کھولیں۔
  2. پروجیکٹ کے فولڈر میں سے Documentary_AI_Backend.ipynb فائل کولیب پر Upload کریں۔
  3. کولیب میں مینیو سے Runtime -> Change runtime type میں جا کر T4 GPU منتخب کریں۔
  4. سیل نمبر 1 اور سیل نمبر 2 چلائیں (Run کریں)۔
  5. چند سیکنڈز بعد کولیب کے نیچے آپ کو ایک لنک ملے گا جیسے: https://xxxx.trycloudflare.com
  6. اس لنک کو کاپی کر کے اوپر والے باکس میں پیسٹ کریں اور Connect کا بٹن دبائیں!

🇬🇧 Step-by-Step English Workflow:

  1. Visit colab.research.google.com and upload the notebook Documentary_AI_Backend.ipynb.
  2. Ensure GPU is enabled (Runtime > Change runtime type > T4 GPU).
  3. Run the cells sequentially. Cloudflare Tunnel will automatically generate a free public HTTPS address.
  4. Copy the https://*.trycloudflare.com URL and paste it into the URL bar of this website.
  5. Click Connect & Test. Once green, click Generate to render your documentary!
